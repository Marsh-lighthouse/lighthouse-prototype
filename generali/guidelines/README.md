# Brand guidelines

Marsh / Mercer Lighthouse visual guideline material used to build this design system.
See the top-level **[DESIGN.md](../DESIGN.md)** for the distilled, developer-facing version
(colours, typography, tokens, phone styles, and §11 graphic language).

## In this folder
- **`graphic-guidelines.md`** — distilled Marsh *Graphic* visual guidelines
  (frame, window treatment, arrow, M-patterns, line elements, and the do/don't list).
- **`pages/graphic-1…5.jpg`** — the source guideline **page renders** (visual reference):
  1. `graphic-1-frame.jpg` — the frame
  2. `graphic-2-layouts-window.jpg` — frame layouts + window treatment
  3. `graphic-3-arrow-patterns.jpg` — arrow graphic + patterns
  4. `graphic-4-patterns-lines.jpg` — patterns (expressive ↔ discreet) + line elements
  5. `graphic-5-lines-tips.jpg` — line elements + tips (avoid)

## Where colour & typography came from
The **colour tokens** (`../brand/marsh-tokens.css`, `../design-tokens.json`) were extracted from
the **Color Guidelines PDF**, and the **type rules** (Marsh Serif 400 / Noto Sans, sentence case)
from the **Typography Guidelines PDF**. Those two source PDFs and their page renders live in the
Claude Design project (`uploads/color Guidlines.pdf`, `uploads/Typography Guidlines_compressed.pdf`,
`uploads/color-page-*.png`, `uploads/type-page-*.png`) — their content is already captured in
DESIGN.md and the token files, so nothing is missing for implementation.
